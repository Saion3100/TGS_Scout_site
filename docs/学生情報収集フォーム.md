# 学生情報収集 Googleフォーム設計

## 1. 目的

TGS SCOUTサイトへ掲載する学生情報を、Googleフォームで収集します。

学生には回答しやすい日本語の質問を提示し、回答内容を `data/students.json` の各項目へ変換します。

## 2. フォーム冒頭の説明文

> このフォームは、TGS 2026出展作品と制作に参加した学生を企業関係者へ紹介する「TGS SCOUT」サイトの掲載情報を収集するためのものです。
>
> 回答いただいた氏名、プロフィール、スキル、希望職種、ポートフォリオなどの情報は、学生の作品・技術・就職意向を企業関係者へ紹介し、面談・採用・インターンの相談につなげる目的で利用します。
>
> 回答内容は確認・編集したうえでサイトへ掲載します。学生個人の連絡先は掲載せず、企業からの連絡は学校が窓口となります。

## 3. 学校側で設定する項目

次の項目は学生から収集せず、学校側で設定します。

| JSON項目 | 内容 |
|---|---|
| `id` | サイト内で使用する学生ID |
| `name_en` | 氏名のふりがなをもとに作成する英語表記 |
| `is_active` | サイトへの公開状態 |

トップページの注目学生情報を管理する `featured_students.json` も、教員側で設定します。

---

## 4. Googleフォームの質問

### セクション1：基本情報

#### 1. 氏名

- JSON項目：`name`
- 回答形式：記述式
- 必須：はい
- 説明文：姓と名の間に全角スペースを入れてください。
- 回答例：`国際 太郎`

#### 2. 氏名（ふりがな）

- JSON項目：`name_kana`
- 回答形式：記述式
- 必須：はい
- 説明文：ひらがなで入力し、姓と名の間に全角スペースを入れてください。
- 回答例：`こくさい たろう`

#### 3. 卒業予定年度

- JSON項目：`graduation_year`
- 回答形式：プルダウン
- 必須：はい
- 選択肢例：
  - `2027年卒`
  - `2028年卒`
  - `2029年卒`

#### 4. 所属コース

- JSON項目：`course`
- 回答形式：プルダウン
- 必須：はい
- 選択肢例：
  - `ゲームプログラマコース`
  - `ゲームグラフィックコース`
  - `ゲームプランナーコース`
  - `ゲームサウンドコース`

#### 5. メインの職種

- JSON項目：`role`
- 回答形式：ラジオボタン
- 必須：はい
- 選択肢：
  - `プログラマー`
  - `デザイナー`
  - `プランナー`
  - `サウンド`
  - `その他`

---

### セクション2：希望職種・技術

#### 6. 希望する職種を選択してください

- JSON項目：`desired_roles`
- 回答形式：チェックボックス
- 必須：はい
- 設定：複数回答可、「その他」を有効にする
- 選択肢例：
  - `ゲームプログラマー`
  - `グラフィックスプログラマー`
  - `ツールエンジニア`
  - `3Dデザイナー`
  - `2Dデザイナー`
  - `UIデザイナー`
  - `ゲームプランナー`
  - `レベルデザイナー`
  - `サウンドデザイナー`
  - `コンポーザー`

#### 7. 使用できる技術・ツール・ソフトウェア

- JSON項目：`skills`
- 回答形式：記述式
- 必須：はい
- 説明文：複数ある場合は読点（、）で区切ってください。
- 回答例：`C++、Unreal Engine 5、Git`

#### 8. 得意分野・専門分野

- JSON項目：`fields`
- 回答形式：記述式
- 必須：はい
- 説明文：自分が特に得意としている分野を3つ程度まで入力してください。複数ある場合は読点（、）で区切ってください。
- 回答例：`ゲームプレイ、グラフィックス、ツール開発`

---

### セクション3：プロフィール

#### 9. あなたの強みを一言で表してください

- JSON項目：`headline`
- 回答形式：記述式
- 必須：はい
- 説明文：プロフィールの見出しとして掲載します。30文字程度で入力してください。
- 回答例：`遊びの手触りを、コードで磨く。`

質問への回答が難しい場合は、次の質問文に変更し、回答をもとに学校側で見出しを作成します。

> あなたが制作で最も大切にしていることは何ですか？

#### 10. 自己紹介・制作に対する姿勢

- JSON項目：`bio`
- 回答形式：段落
- 必須：はい
- 説明文：得意なこと、制作で大切にしていること、今後取り組みたいことなどを100〜200文字程度で入力してください。

---

### セクション4：面談・インターン

#### 11. 企業との面談を希望しますか？

- JSON項目：`interview_available`
- 回答形式：ラジオボタン
- 必須：はい
- 選択肢：
  - `はい`
  - `いいえ`

回答登録時に「はい」を `true`、「いいえ」を `false` へ変換します。

#### 12. インターンシップを希望しますか？

- JSON項目：`internship_interest`
- 回答形式：ラジオボタン
- 必須：はい
- 選択肢：
  - `はい`
  - `いいえ`

回答登録時に「はい」を `true`、「いいえ」を `false` へ変換します。

---

### セクション5：ポートフォリオ・成果物

#### 13. ポートフォリオ・作品資料のURL

- JSON項目：`portfolio_url`
- 回答形式：記述式
- 必須：はい
- 説明文：Google Drive、VIVIVITなど、企業へ公開できるURLを入力してください。Google Driveを使用する場合は、閲覧権限を「リンクを知っている全員」に設定してください。

#### 14. 公開可能なソースコードのURL

- JSON項目：`source_code_url`
- 回答形式：記述式
- 必須：いいえ
- 説明文：GitHubなど、企業へ公開できるソースコードがある場合に入力してください。

#### 15. 公開可能な作品・自己紹介動画のURL

- JSON項目：`video_url`
- 回答形式：記述式
- 必須：いいえ
- 説明文：YouTubeなど、企業へ公開できる動画がある場合に入力してください。通常の視聴ページのURLを入力してください。

---

## 5. 回答データの変換ルール

| フォーム回答 | JSONへの変換 |
|---|---|
| チェックボックスの回答 | JSON配列へ変換 |
| 読点で区切られた技術・専門分野 | 読点で分割してJSON配列へ変換 |
| 面談・インターンの「はい」 | `true` |
| 面談・インターンの「いいえ」 | `false` |
| 任意URLの未回答 | 空文字 `""` |
| YouTubeの視聴URL | サイト登録時に埋め込みURLへ変換 |

```json
}
```
