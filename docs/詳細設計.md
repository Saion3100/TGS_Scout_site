
## 2. システム構成・ディレクトリ構造

学校のレンタルサーバー（PHP環境）に最適化した構成です。

```
/ (root)
├── index.php              # トップページ（作品・学生への導線）
├── teams.php              # 全チーム一覧
├── team_detail.php        # チーム詳細（QR遷移先・メンバー一覧）
├── students.php           # 全学生一覧（職種・技術での絞り込み）
├── student_detail.php     # 個人プロフィール（制作物プレビュー）
├── contact.php            # 問い合わせフォーム（UIのみ）
├── assets/
│   ├── css/               # 白・赤基調のスタイルシート
│   ├── js/                # 検索フィルタリング、動画制御
│   └── img/               # 共通ロゴ、バナー等
├── data/
│   ├── students.json      # 学生データ（JSON）
│   ├── teams.json         # チーム・作品データ（JSON）
│   └── mapping.json       # チームと学生の紐付けデータ
└── includes/
    ├── header.php         # 共通ヘッダー
    └── footer.php         # 共通フッター
```

## 3. データ構造設計（JSON）

### 3.1 `students.json` (学生基本情報)

```
{
  "id": "s28_001",
  "name": "国際 太郎",
  "role": "Programmer",
  "skills": ["C++", "DirectX12", "HLSL"],
  "drive_pdf_id": "FILE_ID_FOR_PREVIEW",
  "video_url": "https://www.youtube.com/embed/...",
  "is_active": true
}
```

- **デザイナー**の場合は、VIVIVITのURLを保持します。
- **プログラマー**は、PDFプレビューに加え、ソースコードZIPへのリンクをオプションで保持します。

### 3.2 `teams.json` (作品情報)

```
{
  "id": "t01",
  "game_name": "スライムバスターズ",
  "booth_no": "09-C01",
  "description": "作品の概要・注目ポイント...",
  "thumbnail": "path/to/img.jpg"
}
```

## 4. 画面詳細・ロジック設計

### 4.1 チーム詳細ページ（QR遷移先）

- **機能**: 各試遊台のQRコード（`team_detail.php?id=t01&src=tgs_booth`）から直接流入。
- **表示**: `teams.json`から作品情報を、`mapping.json`を介して所属メンバーを抽出。
- **レイアウト**: メンバーを「プログラマー」「デザイナー」「プランナー」といった職種別にグループ分けして表示します。

### 4.2 個人プロフィールページ

- **PDFプレビュー**: Google Driveのプレビュー用URL（`https://drive.google.com/file/d/{ID}/preview`）を `<iframe>` で埋め込み、1ページ目がサイト上で直接見えるようにします。
- **動画再生**: ゲーム紹介動画（約1分程度）を埋め込み、技術力のフックとします。

### 4.3 問い合わせフォーム（UIのみ）

- **選択アクション**: 以下の5種類を選択肢（ラジオボタン等）として実装します。
    1. 学校の先生に連絡したい
    2. 説明会の相談をしたい
    3. この学生と話をしたい
    4. この学生に応募してほしい
    5. この学生に注目している
- **自動設定**: 遷移元の学生名またはチーム名をフォーム内に自動補完します。

## 5. UI・デザイン仕様

- **カラー**: 背景 `#FFFFFF`（白）、アクセント `#E60012`（赤）。
- **モバイル対応**: 閲覧の主軸はPC（会社での比較検討用）としつつ、会場でのスマホ閲覧でもレイアウトが崩れないレスポンシブ設計を徹底します。
- **タップ範囲**: モバイル操作を考慮し、ボタンやリンクのタップ範囲を44px以上確保します。

---

## 6. 非機能要件

- **検索エンジン拒否**: 採用関係者限定とするため、全ページに `noindex` を設定します。
- **表示速度**: 画像の遅延読み込み（`loading="lazy"`）や軽量なJSON読み込みにより、初期表示3秒以内を目指します。
- **セキュリティ**: 問い合わせフォームの入力値に対してPHPの `htmlspecialchars()` を適用し、XSSを防止します。
